A tool for creating a pdf based on a csv of song titles and artists, using the lyricsgenius api, a wrapper for the genius api.

You must create your own token at genius.com/api-clients and add it as an environment variable. Copy the token to your clipboard.

`export LYRICS_GENIUS_TOKEN=your-token-here`
There should be no output. 

Finally, sample usage:
`python3 lyrics.py`
When prompted, type:
`sample_data.py`
